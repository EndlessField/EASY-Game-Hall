## 快速开始

双击 `index.html` 即可进入主页（推荐入口）。三个游戏页面集中存放在 `game/` 子目录（英文文件名），也可直接打开任意页面：

```
index.html                主页 —— 新手教程 / 战绩速览(含军衔) / 存档槽位 / 存档导出导入 / 四大入口 / 五图预览
game/hub.html             整备大厅 —— 装备 / 难度 / 地图 / 18 项永久升级 / 军衔晋升 / 成就(15) / 存档槽位 / 存档导出导入
game/breach.html          游戏本体 —— 战斗 / 7 步互动教程 / 训练场(?range=1) / 设置与改键
game/street.html          独立玩法 —— 长街波次防守(借用手感机制, 共用成长存档)
```

主页与三个游戏页共享浏览器 `localStorage`：准备页配好的装备与升级自动带入游戏，战斗结算的军功点与战绩自动回写。**《丧尸围城·长街尸潮》是独立玩法页**（自带主页入口），只借用本作上帝视角手感与装备/升级/难度/军功点体系：地图为**横向长街**（南北两排沿街建筑＋1.8m 人行道＋9.6m 双向街道＝2×3m 车行道＋两侧路内停车带，4 处 4m 巷口上下对齐、巷口画斑马线，街两端与巷口刷尸），规则独立（无限波次+波后补给+周期性强化），与红蓝对抗战役互不影响。

### 安装 / 更新程序（`install.bat`，随发布包分发）

发布包根目录带一个 `install.bat`（源码在 `.uiwork/pkg/install.bat`，由 `.uiwork/build-package.ps1` 打进包），玩家双击即可安装：

1. **WebView2 检查**：查注册表（HKLM WOW6432Node / HKLM / HKCU 的 `EdgeUpdate\Clients`）→ `%ProgramFiles(x86)%\Microsoft\EdgeWebView\Application\msedgewebview2.exe` → 该目录下的版本号文件夹，三层兜底；缺失且包内有 `MicrosoftEdgeWebView2RuntimeInstallerX86.exe` 时先 `/silent /install`，非管理员静默失败就弹官方安装界面。**游戏本身不需要 WebView2（纯本地网页），所以缺了也不阻断安装。**
2. **询问安装目录**：默认 `%LOCALAPPDATA%\交火`；已存在 `index.html` 就按「更新」处理（`xcopy /E /Y` 覆盖游戏文件，保留导出存档等外部文件）。
3. **版本比对**：包版本从 `VERSION.txt` 读（回退：目录名 `交火_vX.Y.Z` → `REV. 版次`），已装版本从目标目录 `VERSION.txt` 读（回退：用 ASCII 正则从 `game\breach.html` 的 `tb-v">v3.3` 里取，**不用中文正则，避免代码页问题**）。包比已装**旧**时报警并要求输入 `Y` 二次确认（可用 `/yes` 或 `CF_YES=1` 跳过询问）。
4. **桌面快捷方式**：用 `WScript.Shell` 生成 `%USERPROFILE%\Desktop\交火.lnk`，目标 = 安装目录的 `index.html`，图标 = 包内 `photo.ico`。脚本宿主被禁用时只提示，不影响安装。

自动化参数：`install.bat /dir:"<目录>" [/yes]`，或环境变量 `CF_DIR` / `CF_YES=1`（**路径带空格时用环境变量更省事**）。排障靠 ASCII 标记行 —— 安装器会打出 `CF:PKG=` / `CF:DIR=` / `CF:STATUS=` / `CF:VER=` / `CF:CMP=` / `CF:DECISION=` / `CF:COPY=` / `CF:LNK=`，这些标记不受控制台代码页影响，自动化断言只认它们。场景回归：`powershell -NoProfile -ExecutionPolicy Bypass -File .uiwork\install-test.ps1`（六个场景：全新安装 / 同版本重装 / 降级拒绝与强制 / 老安装无 VERSION.txt / 路径带空格 / 包不完整）。

> 两个已踩过的坑记在这里，改 `install.bat` 前先读：① 文件按中文 Windows 惯例存成 **GBK + CRLF**（`chcp` 与括号块里的中文在旧版 cmd 下会被二次解码，故脚本内**不使用括号块**，全部改 `goto` 分流）；② `EnableDelayedExpansion` 下 `for /f … do set X=%%a & set Y=%%b` 与 `set "%~1=值"` 这类写法在实测中失效，**一律显式写变量名**。

## 玩法

- **红方**：你（人类）+ 2 台友军机器人，驻守左户客厅；**蓝方**：4~6 台敌方机器人（按难度）驻守右户各房间。
- **目标**：肃清全部蓝方机器人。**一梯两户板式住宅**（单户 10.2m × 9.6m ≈ 98m²，三室两厅一厨一卫＋南阳台）：北侧三间卧室全部贴外窗；0.8m 内走廊串起三扇卧室门与卫生间门，东端敞开接餐厅；厨房与餐厅相邻并以门相隔（油烟不外溢）；南侧客厅与餐厅敞通、东端经推拉门进阳台；入户防盗门开向公共电梯厅，进门即玄关。中央核心筒＝楼梯间＋电梯井（实心井道，不可进入）＋电梯厅，散落弹药 / 医疗包 / 手雷 / 闪光弹 / 烟雾弹 / 炸药包补给。
- **真实视线**：锥形视野 + 墙体/关门遮挡 + 战争迷雾 + "最后目击"**记忆标记** —— 敌人脱离你和队友的视野后，会在**最后一次被看到的位置**留下一个**点划线圆 + 问号**（图纸式记忆标记，保留 3 秒；`GHOST_T` 可调，设 0 即完全不留），**不跟随敌人的实时坐标**（否则那 3 秒等于透视），也不再画成"半透明实体"（那会让人以为它是真单位、消失时很突兀）；枪声会暴露位置，敌人会循声查探、破门突入；**烟雾弹**会生成持续 7 秒的烟雾云，遮蔽敌我双方视线。
- **AI 战术**：BFS 寻路（转角路点 + 轴分离滑墙穿门）、找掩体、侧翼包抄、反应延迟、**低血撤退**、掩护射击（队友贴近目标点时停火压制、其余推进）、**倒地救援**（友军机器人倒地后 10 秒内可被队友扶起）、听声查探。
- **战术指令**：按 `1`/`2`/`3` 选中 红机A/红机B/全部（选中者带绿色高亮圈），按 `X` 进入**指令模式**后左键点地图可给队友下**移动命令**（到达后自动原地固守）；`C` 跟随我、`V` 固守原地、`B` 集火准星附近的可见敌人（含"最后目击"追踪，不会隔墙透视）。
- **HUD 防遮挡**：左上玩家信息 / 右上目标信息面板是画布浮层，当单位或准星进入面板区域时该面板自动淡出（仅被挡住的那块），移开后恢复——不再挡住交火单位。**教程面板（左上，7 步批注）与底部键位提示条走同一套判定**：教程全程在左户活动，而面板正压在左户上，所以单位或当前步骤的黄色目标圈一进面板矩形，面板就淡出让位——原来"教官面板挡住该看的点"的问题由此消除（两条面板的几何进 `PANEL_FALLBACK`，无布局环境下也按同一矩形判定）。
- **武器**：突击步枪 / 冲锋枪 / **霰弹枪**（近战爆发：每发 8 颗弹丸扇形散射、单颗 11 伤 —— 贴脸全中 88，一枪带走 60~76 血的守军；0.1rad 固定扇面在远处自然散开，500px 处最多中 4 颗，所以它是"贴脸才强"的枪；泵动 2.0 发/秒、8 发弹匣、换弹 1.9s）/ **狙击枪**（一发入魂，右键开镜放大 2.2 倍并带镜圈压暗效果，镜头以准星为锚点不漂移、关镜自动回中）/ **轻机枪**（75 发大弹匣持续压制，精度差、换弹慢）/ **精确射手步枪**（单发 30 伤、开镜 1.8 倍），外加**手枪副武器**（按 Q 随时切换，各自独立弹匣与换弹进度）。**所有武器点击即射**：射速积分器在待机时按同一速率回充（封顶 1 发），距上一发满 1/射速 秒后按下左键**当帧出膛**，不必按住半个射速周期（霰弹枪 0.5s、狙击 1.05s），换弹完成与切枪也直接是"上膛待发"；连点无法绕过射速上限，掉帧大时间步下连射射速也不掉。**六把主武器在长街尸潮页同样全部可用**（准备页选什么就带什么进尸潮；两张页面的武器表由 `tests/meta_test.js` H5b 逐项比对，漏同步会直接测试失败）。
- **AI 寻路**：寻路网格按"单位半径+余量"保守判定，**窄于 26px 的缝隙直接不可走**，机器人不会卡缝顶墙鬼畜；地图家具一律遵守"**贴墙（≤20px 缝）或留 ≥44px 过道**"的摆法，避免出现"物理上能挤进去、寻路网格却没有出口"的死角（`tests/map_probe.js` 可复检）；单位被爆炸/队友挤进贴墙死角时，`findPath` 会把起点就近吸附到**直线无遮挡**的可走格再规划，配合轴分离滑墙与墙角瞬移脱困，不会原地打转。
- **炸药包**：大范围高伤害爆炸，还能**炸毁爆炸半径内的家具**（低掩体消失、寻路与碰撞自动重建）。
- **破墙锤（H）**：贴着**内隔墙**按住 `H` 1.4 秒即可砸开一个 0.72m 的洞（承重外墙与核心筒井道不可破坏）。破洞是真·结构改动——墙段一分为二、两端留门垛，碰撞/视线/寻路/小地图全部按既有数据流自动重建，于是每张图都多出若干条**玩家自选的新进攻路线**；代价是砸墙声会暴露位置（噪音半径 620）。
- **声源诱饵（Z）**：投掷式发声器，落地后 4.5 秒内每 0.7 秒发声一次（半径 780），**把守军"调"到另一个方向**——不造成任何伤害，纯粹是主动的调虎离山；它复用既有 AI 的"听声查探"分支，所以机器人不会识破。默认 2 枚，地图上另有补给。
- **配电箱 / 断电（E）**：每张图有一个配电箱（贴着一段实体墙，小地图上探索后常驻显示，合闸绿/断电红）。靠近按 `E` 拉闸后**全场变暗、双方视野同时收缩**：机器人 ×0.6、玩家 ×0.78（你有手电）——断电因此是**玩家的战术选项**而不是纯惩罚，但你也同样更晚发现敌人。
- **小地图批注（工具条「批注」按钮）**：开启后在右下角索引图上**按住左键拖拽画红蜡笔箭头**（单击撤销上一笔、双击全部擦除），最多保留 12 笔。批注存的是世界坐标，换图/缩放都不会错位；批注模式默认关闭，且只在索引图区域内拦截左键，**不影响正常瞄准与射击**。索引图本身**默认收起**，开批注会自动把它放出来（收起索引图 = 批注没有落点，会一并关闭）。
- **战后作业图（结算页 + PNG 导出）**：每 0.25 秒给所有单位打一个采样点，结算时把整局走位画成一张图纸——红/蓝轨迹、阵亡叉号、交火/爆炸圈号、房间分区、制图网格、图框与图签（含真实比例尺）。结算页可一键**导出 PNG**（`canvas.toDataURL` 由浏览器编码，仍然零网络依赖）。
- **图签栏接真数据**：四张覆盖层（开局/暂停/结算）右下角的图签栏不再是装饰——**图号 = `BR-<地图>`、比例 = 本局击杀比（玩家击杀 : 蓝方总数）、张次 = 当前档案槽**。
- **蓝晒载入曝光**：每局开始时晒图机在纸面上走一遍（纯 CSS 动画、不阻塞任何游戏逻辑、不吃指针事件，`prefers-reduced-motion` 下自动关闭）。
- **地图**：**五张战役地图**（**战前准备页与开局界面都可选**，写入 `cfg.map` 自动带入；教程固定户型图）。五图全部按现实空间逻辑重做，比例尺约 **1px ≈ 1cm**，门宽 0.8~1.3m、走廊 0.8~1.6m、车位 2.5×4.3m、车道 4.6~5.5m、货架排 1.3m 深＋3m 巷道——不是"房间方阵"，而是按真实动线组织：

- **长街·尸潮寻路（B7）**：让尸群"散开包过来"而不是排队硬挤。①**目标格吸附**——你和丧尸贴在路边车/墙/工事上时（碰撞半径 11 < 寻路网格 pad 13），旧实现 `findPath` 会直接失败、全队退化成直线冲墙；现在起点与终点都会就近吸附到可走格。②**个人分流**——每只丧尸有稳定的"个人站位角"，距目标较远时各自瞄准目标周围的站位点（偏移量随距离渐入，**贴脸自动收敛到本人**，不会卡在包围圈上咬不到人）。③**局部绕行**——前方两身位内挤了 ≥2 只同伴时沿切线甩向更空的一侧（29°、最多 96px，被载具挡住会换边/缩短）。④**错峰重寻路**——每只的寻路冷却在 0.22~0.36s 间固定错开，避免上百只同帧做 BFS 的帧尖峰。⑤**大体积跟点校验**——胖子(r=16)与尸王(r=26)按 16px 网格规划出的路点可能实际挤不过去，跟点前用真实半径校验并跳过（`CROWD` 参数块集中调平衡）。

- **长街弹药与弹夹经济（B5·街 二次调整）**：本页**不再投放医疗包**（治疗全部交给脱战回血 + 波间整补 + 战地急救），波次结算固定投放 **6 箱弹药 + 1 手雷 + 1 闪光**（街面留存上限 10，尸王额外补给改为 2 弹药 + 手雷 + 闪光）；**每箱弹药 = 当前弹夹容量 × 2**（例：30 发弹夹 → 60 发，随弹夹扩容自动变多，搜刮效率仍作用于整箱总量，备弹上限 999）。**弹夹容量成为本局成长线**：每肃清 3 波**永久 +50% 基础弹夹容量**（上限 3 倍，即 30 发的步枪 → 45 → 60 → 75 → 90 发），强化面板也新增第 8 项「弹夹扩容 +50%」，两条路径共用同一套上限（`raiseMagCap`/`setMagCap`）；HUD 常驻显示当前弹夹容量与扩容档位。升级表相应**移除 `med`（医疗包效率）**——本页已无医疗包，保留即为死升级；其余 id/上限与主游戏同源，由 `tests/meta_test.js` 守护。结算口径不变（1 + min(肃清波数, 15)）。
- **存档槽位（3 档）**：主页与准备页均可切换「档案 1/2/3」，每个档案独立保存配置与进度（槽位按钮直接显示该档军衔与军功点）；**档案 1 沿用历史存档 key**，老玩家数据自动落在 1 号档案，导入/导出/重置只作用于当前档案。游戏设置与键位是全局偏好，不随档案切换。

## 界面视觉系统（突入作业图 / BREACH WORKS DRAWING SET）

四个页面共用一套**纯 CSS 视觉语言**（不引用任何外部字体或图片资源，图标全部来自本地 FontAwesome 免费集，四个页面共用到 150+ 个图标），在每页 `<style>` 顶部有完整注释，**完整设计系统见本节**。改 UI 时请沿用这套令牌，不要在页面里另起一套配色。

世界设定：整套界面 = 一叠摊在制图台上的**突入作业图纸**。游戏是"一张户型图上的红蓝对抗"，所以界面不再假装自己是一块终端屏幕，而是蓝晒工程图：

- **配色**：深普鲁士蓝的**纸面**（页面底 `#061624` / 面板 `#0b2434` / 次级面 `#0f2e43`）＋ 象牙白的**墨线**（`#e8eef0`）。**青 `#5ecbff` 只给选中、主动作、链接、焦点**；**黄蜡笔 `#ffc34d` 只给军功点、星级、教程、波次**；**红蜡笔 `#ff5b47` 只给危险、失败、阵亡、尸潮**；绿只给通过。每页 `:root` 同时保留全部旧变量别名（`--gold` / `--txt` / `--panel-top` / `--chip` 等），因为页面与 JS 行内仍在使用。
- **形状**：`border-radius` 恒为 **0**。「色条 + 细框」一律交给 `border-image` 直角拼接——直接用不同宽度的 border 会被浏览器在角上斜接（miter）出一道小斜边。**注意**：父级若用 `border-image` 画粗色条，子元素上的细 `border-left` 必须写 `border-image:none` 复位，否则父级的 border-image 会吃到子元素的细边上（表现为多行段落只剩一小段色条）。
- **装饰语法（用"线"和"标注"说话，不靠发光和渐变）**：面板是**图纸**（图框 + 四角 L 形对位标记 + 图签栏 `图号 / 比例 / 张次`）；数据是**标注**（尺寸链带端部刻度、引线注记、编号方块、`注：` 说明）；**状态用线型表达**——实线=正常、点划线=未达成、剖面线=危险、**象牙白实底反转=当前选中**。另有 45° 剖面线、比例尺、指北针、制图网格（10px 细格 + 50px 粗格）。全部为纯 CSS 渐变与伪元素，**没有背景图**。
- **字体**：中文永远是「Microsoft YaHei / PingFang SC / Noto Sans SC」；拉丁装饰字与图号走 `Bahnschrift SemiCondensed / Arial Narrow / Oswald` 这一链，**数值一律等宽（`Consolas` + `tabular-nums`）**——图纸上的数字必须对齐。系统缺字时逐字回退，中文不受影响。不联网取字、不写 `@font-face`（`tests/offline_test.js` 会拒绝）。
- **无障碍**：四页都尊重 `prefers-reduced-motion`；复选框与滑杆是**原生 input 加直角外观**（保留键盘与读屏）；正文/提示文字对比度满足 WCAG AA；提示行（主页 `#shareHint`、整备大厅 `#toast`）带 `role="status" aria-live="polite"`。
- **无布局环境下的 Canvas 兜底**：`hub.html` / `index.html` 的地图预览用 `measureText` 量出出生点标签宽度再垫底色，自动化测试的 2D 上下文桩没有返回值，故该处必须带 `try/catch` + 估算宽度回退。地图预览本身也按蓝晒线稿绘制：墙=象牙白粗线、门洞=黄蜡笔断口、出生点=方框十字制图符号。
- **游戏内 HUD**：`breach.html` / `street.html` 的 HUD 被当作"盖在图纸上的现场标注层"——细线框 + 象牙白定位条 + 尺寸刻度（血条带 10% 刻度、弹药条带 25% 刻度），`breach.html` 的小地图是一张带标题的**索引图（Key Plan）**（默认收起，按需展开），覆盖层（开始/暂停/结算）是一张**盖住战场的图纸**（四角对位标记 + 图签栏）。
- **对局 HUD 从简（视野优先）**：HUD 上只留"这一刻要读的数"——生命条、武器与弹药（一行）、携行装备与状态（一行图标读数）；右上角战况压成**一行条**（时间 / 击杀 / 红‧蓝）；**索引图默认收起**，工具条「索引图」按钮按需展开（收起时连小地图与它的迷雾层都不绘制）；击杀播报只留**最近 2 条 × 2.4 秒**；底部键位表**默认只常驻一行**（移动/射击/换弹/互交），完整键位由工具条「**操作提示**」按钮展开（会话级开关，改键后提示条照旧实时重绘）。窄窗口另有两档：**≤960px** 工具条移到底部居中并收成图标（让出顶部给面板与播报），**≤680px** 两块面板各占一半宽、提示条让开索引图。实测 1440×807 下 HUD 占屏 **5.1%**（原 20.5%；展开索引图 7.1%、展开全键位表 9.2%），三个尺寸下各构件**零重叠**。

### 移动端（v3.5.0 起）

- **断点**：`max-width:960px` 使用手机界面；游戏页的触控层同样只在 `window.matchMedia('(max-width:960px)')` 命中时绑定。桌面（>960px）仍走原来的键鼠路径，CSS/JS 均不改变桌面布局。
- **主页**：新增 `.mob-topbar`（军衔/军功点/账户）、`.mob-hero`（开始/整备）、`.entry` 拇指卡与 `.mob-nav` 底部导航；`mobSync()` 把桌面读数镜像到顶栏。桌面头部、入口卡、档案槽位、数据工具、简报/教程/贴士/排行榜原样保留，移动端只换排布与皮肤。
- **整备大厅**：`data-mob="action|build|stats|more"` 标记分页，`.mob-on` 控制当前页，`mobHubTab()` 切换；底部固定「开始行动」调用原 `#btnGo`，不复制存档逻辑。
- **战役触控**：`mobileMove`（摇杆）叠加进 `updatePlayer` 的移动向量；`mobFrame()` 每帧让镜头跟随玩家并更新准星世界坐标；`#cv` 的 `pointerdown/move/up` 只在 `pointerType!=='mouse'` 时接管「点按/拖动瞄准并开火」，`mouse.down` 仍由原射击循环消费。手雷/闪光/烟雾/炸药/诱饵先武装 `pendingThrow`，下一次点战场才 `doThrow()`；`data-cmd` 面板直接调用原 `orderFollow/orderHold/orderAttack/toggleOrderMode/autoDoor`。
- **长街触控**：同一套 `mobFrame()` 与摇杆；镜头按长街地图边界钳制。波间点战场或「工事」键调用原 `buildSandbag()`，「转向」调用 `rotateBuild(1)`；开始/强化/结算/暂停用整屏卡片。
- **移动端教程文案**：`MOB_TUT_DESC` 按步骤 id 覆盖 `TUTORIAL_STEPS[].desc`，判定逻辑与桌面完全同一套；Node 测试没有 `matchMedia` 时 `mobileUI()` 恒为 false，仍读原文案。
- **手机战斗横屏守门**：战役 / 长街在触屏竖屏时显示 `#mobRotate` 并让 `loop()` 在 `mobPortrait()` 为真时直接返回（冻结模拟、不渲染）；横屏后自动恢复。提示页的「尝试自动横屏」按钮请求全屏 + `screen.orientation.lock('landscape')`，失败则提示手动旋转。桌面与无触屏窄窗口不会触发。
- **星形图标**：`i.fa-star.dim` 增加了专用重置（`.dim` 是尺寸线类，原先会把星形压成 1px 线并覆盖 FontAwesome 的 `::before`），四页通用。
- **验证**：25 个断言测试全绿；另用 Edge Headless + CDP 在 390×844、320×640、844×390 与桌面 1440×900 截图复核，确认无横向溢出、触控可走位/开火/换弹/投掷。

> **改 UI 的红线**：`tests/` 下的脚本直接读这四个页面的源码，或把 `<script>` 送进 `vm` 执行，所以**元素 id、`<link href>` 目标、跳转文件名、`// ---------- 章节 ----------` 标记、以及注入 `innerHTML` 片段里的类名都必须保留原样**。另外三页源码还被这些正则扫描：CSS 里不得出现 `url(`、`@font-face`、`@import`，不得新增 `<link>` / `<script>` / `http(s)://` / 协议相对 URL / emoji，主 `<script>` 必须是**裸标签**（不能加属性），`breach.html` 必须仍含 `蓝方5人` / `蓝方6人` 且不得出现 `蓝方7人` / `蓝方8人`，`index.html` / `hub.html` 的 `<map-preview-data:auto>` 数据块逐字节比对。改完务必重跑 `node tests/run_all.js`。

## localStorage 协议

**存档槽位**：活动槽位号存 `breach_game_slot`（1|2|3，缺省 1）。槽位 1 沿用下列历史 key，槽位 N(≥2) 加 `_sN` 后缀（如 `breach_game_save_s2` / `breach_game_cfg_s2`）。

**账户（v3.2，可选）**：没建过账户时，下表就是全部真相（明文、无锁、与旧版完全一致）。**一旦建了账户**，`cfg / save / set`（含 `_s2` / `_s3`）会被写进**带账户前缀的键**并以**信封**（密文 + 随机数 + HMAC 校验码）落盘：

| 模式 | 进度与设置落在哪 | 形态 |
|---|---|---|
| 没建账户（`legacy`） | `breach_game_cfg/save/set(_sN)` | 明文 JSON（老档、老流程不变） |
| 账户已解锁（`account`） | `breach_game_acct_<id>_cfg/save/set(_sN)` | 信封 `{app, enc:'acct-store-v1', nonce, tag, data}` |
| 游客（`guest`） | `breach_game_cfg/save/set(_sN)` | 明文 JSON；**每次进入游客模式即清空** |
| 有账户但未解锁（`locked`） | 读不到（`vaultRead` 返回 null），**写入一律拒绝** | — |

| Key | 内容 | 写入方 | 读取方 |
|---|---|---|---|
| `breach_game_cfg` | `{ version, diff, weapon, map, upgrades:{id:等级} }` | 准备页 | 游戏页 / 长街玩法页 |
| `breach_game_save` | `{ version, rank, points, stats:{wins,losses,kills,damage,bestStars,ach,shots,hits,longKill,bestStreak,gKills,time,ff,winStreak,bestWinStreak,mapWins}, daily:{日期:{stars,time}}, streetBest, streetWaves, streetBosses }` | 游戏页 / 长街玩法页 | 准备页 / 主页 |
| `breach_game_set` | `{ version, vol, shake, fps, adsHold, sens, crosshair, crossSize, hitmarker, autoDoor, keys:{动作:键码} }` | 游戏页(暂停菜单/工具条按钮) | 游戏页(启动回读) |
| `breach_game_accts` | `{ v, app, list:[{id,user,salt,iter,ver,fp,at}], last }` —— **明文**，只有用户名/盐/口令校验值/指纹，**不含口令与任何进度** | 主页 / 整备大厅(账户界面) | 四个页面(判断是否上锁) |
| `breach_game_session` | `{ v, id, fp, key, mac }` 或 `{ v, guest:true }` —— 会话（**sessionStorage**，不在 localStorage） | 登录/建账户/进游客 | 四个页面(判断是否已解锁) |
| `breach_game_board` | `{ v, app, campaign:[{stars,time,kills,map,mapName,diff,who,at}], street:[{waves,score,boss,evac,diff,who,at}] }` —— **明文且全机共用**（含游客）：排行榜要能被任何身份看到与写入，且不含任何存档内容 | 战役页 / 长街页(结算时) | 主页 / 整备大厅(榜单面板) |

> 账户模式下 `breach_game_set` 从"全局偏好"变成**每个账户一套偏好**（音量/准星/键位随账户走并一起加密）；游客与无账户模式仍是全机共享的明文偏好。`breach_game_slot`（当前用哪个档案槽）**始终明文全局** —— 它只记录"用哪个槽"，不含任何进度信息。

存档、配置与设置均带 `version` 字段：读取时按版本补齐缺失字段（`migrateSave`/`migrateCfg`/`migrateSet`，版本号只升不降），旧存档自动补默认字段，未来加字段不会读挂旧档。当前 `SAVE_VERSION = 2`（v2 起累计统计/地图胜场/街玩尸王）、`SET_VERSION = 3`（v2 起灵敏度/准星/命中提示/键位，v3 起自动开门）、`CFG_VERSION = 1`。

## 账户与本地加密存储（v3.2，可选）

- **怎么开**：主页或整备大厅工具条上的「**账户**」按钮 → 「创建账户」（用户名 + 口令两遍）→ 建完立即进入该账户。**没建账户时一切照旧**（明文、无锁、老档可读）——账户是可选层，不会把老玩家挡在门外。
- **建账户时会把现存明文进度加密搬进账户**，并删掉明文键：搬完 `breach_game_cfg/save/set` 在 localStorage 里就只剩密文了（`migrated` 条数会写在提示里）。
- **进入**：有账户之后，主页/整备大厅打开时先弹账户界面（选账户 → 输口令 → 进入），也可以选「**游客模式**」。解锁状态存在 **sessionStorage**：同一标签页里 主页→整备→战役→长街 一路跳转不会反复要口令，**关掉标签页就失效**，下次还得输。
- **游客模式（每次重置）**：不需要口令，进度走老明文键，并且**每次进入游客模式都把游客进度清空**（同一标签页内继续跳转不会反复清，否则打到一半切页就没了）。游客与账户各存各的，互不覆盖。
- **游戏页拦截**：直接打开 `game/breach.html` / `game/street.html` 且当前未解锁时，页面**不读档、不开局**，只显示一张"需要先解锁账户"的提示卡（按钮回主页解锁）。账户界面只维护在主页/整备大厅两份，游戏页不内嵌登录框。
- **多账户**：最多 8 个，各自独立口令与进度（`breach_game_acct_<id>_*`），互不可见；可「切换账户」「修改口令」（用新口令重新加密该账户全部存档，数据不丢、旧口令立刻失效）「删除账户」（需该账户口令，密文一并清除）。
- **口令丢了就打不开**：没有找回机制（口令不落盘，只在内存里派生密钥）。重要进度请定期用「导出存档」留一份备份。
- **安全边界（说清楚）**：会话密钥在 sessionStorage 里是明文的，同机开 devtools 的人拿得到；账户清单本身也是明文（用户名可见）。这层挡的是"**随手翻看 / 随手改档**"（家人、同事、共享机器），不是防有心人 —— 与 v3.1 加密导出一致的定位，别把它当银行级保护。
- **实现**：四个页面各带一份**逐字节相同**的模块（`SHA-256` 原语 → 口令派生一次 KDF 再用用途字节切出数据/校验/指纹三把钥匙；落盘用 **SHA-256-CTR 流加密 + HMAC-SHA256 截断 16 字节**，每次写入换新随机数）。`tests/account_test.js` 守护语义，并逐字节比对四页副本（加密原语与账户核心四页一致、账户界面两页一致），防止只改一页造成的漂移。

## 本地排行榜（v3.2）

- **两张榜**：战役（`campaign`）与长街尸潮（`street`）各一张，主页与整备大厅各有一个「本地排行榜」面板，两个面板由**同一份渲染函数**产出，长得完全一样。
- **名次口径（榜单分 = 表现分 × 难度系数）**：难度是成绩的一部分 —— 同表现下 **困难 > 标准 > 简单**（系数 `BOARD_DIFF_W`：**简单 0.85 / 标准 1 / 困难 1.2**，调平衡只改这三个数）。表现分把旧口径折成一个数，分项先后不变：战役 `星级×1000 + 击杀×10 + 用时奖励`（600s 满分线，每快 1s 得 1 分，封顶 600，折出来仍是**星级 → 用时 → 击杀**）；长街 `波数×1000 + 得分`（每 10 分折 1 分，最多折 1000＝一波，折出来仍是**波数 → 得分**）。榜单分相同才回落到这些分项逐项比，完全同级时先到者在前，顺序永远可复现。系数让高难度的高表现能压过低难度的一档（含"困难 2★ > 简单 3★"），这是刻意的；**它只影响名次，结算军功点口径完全不变**。系数与榜分**不落盘**（读榜时按当前系数重算），所以老成绩不用迁移、改系数立刻重排；行尾直接标出「榜分」、难度写作 `困难 ×1.2`，名次为什么这么排一眼能算。只保留前 **50** 条（防止长期游玩撑爆 localStorage），**展示前 10 名**，结算页会告诉你"排行榜第 N 名"（没进前 10 不显示）。
- **写榜时机**：战役在 `saveResult()` 里 —— **只记胜利局**（星级只可能出现在胜利局），教程与训练场不计；长街在 `saveStreetResult()` 里 —— 每次结算都记（含撤离通关），一枪未开且零波的弃局不记。
- **明文且全机共用**（键 `breach_game_board`）：榜要能被任何身份读写，因此**故意不进账户加密命名空间** —— 账户已解锁、游客、账户未解锁三种状态下看到的都是同一张榜，且 localStorage 里是明文 JSON（只有"谁 / 难度 / 地图 / 星级或波数 / 用时或得分 / 时间"，不含任何存档内容）。账户解锁时"谁"记账户名，其余记"游客"（用户名本来就明文存在 `breach_game_accts` 里，不新增泄露面）。
- **容错**：读榜时逐条清洗 —— 越界星级钳到 1~3、负数用时归 0、非法地图回退 `house`、超长名字截断、非对象条目直接丢弃、整块 JSON 坏掉时读成空榜；写不回去也不影响结算。
- **清空**：面板下方「清空排行榜」按钮（带确认），只清名次记录，不动存档、升级与战绩。

## 存档导出 / 导入（分享给朋友）

- 主页与准备页都有「导出存档」：把玩家全部数据（配置 `cfg` + 进度 `save`，含装备/难度/地图/升级/军衔/战绩/成就/每日纪录）打包成一个 `交火存档_时间戳.json` 下载。
- **加密导出（可选口令）**：两页都提供一个「加密导出（口令）」勾选框（`#chkEncExport`），勾上再点导出会先要两遍口令，产出的文件是 `交火存档_…_加密.json` —— **用记事本打开只有密文**（密文/盐/随机数/校验码，看不到任何游戏字段）。对方导入时必须输入同一口令；**口令错、文件被改过、格式不是本游戏的加密档，一律拒绝且不写入任何数据**（不会把本地好档覆盖成坏档）。口令丢失无法找回，重要进度请另留一份不加密的备份。
  - 实现全在页面内、零依赖零联网：`SHA-256`（自实现，纯整数位运算）作为唯一原语 → 口令派生 `SHA256` 迭代（`iter=40000`，`iter/salt/nonce` 都写在文件里，导入按文件参数重算，老文件永远打得开）→ **SHA-256-CTR 流加密**（keystream 块 = `SHA256(encKey + nonce + 计数器)`）→ **HMAC-SHA256 截断 16 字节**做完整性与口令校验（`err:'auth'`）。文件头的 `enc:'sha256-ctr-hmac-v1'` 是算法标识，未知标识直接判 `format` 拒绝；`iter` 缺失或越界（含手改超大）同样当场判 `format`，**不进入 KDF** —— 不给"用一个超大迭代数把页面拖死"的机会。
  - 定位是**防随手翻看 / 防转发丢档**的口令保护（对称口令、文件自包含），不是给高价值数据用的密码学产品；`index.html` 与 `game/hub.html` 各有一份**逐字节相同**的副本，`tests/protocol_test.js` 第 ⑩ 段会互解对方的密文来守护两页同格式。
  - 明文导出路径完全不变（老文件、老导入流程照旧）：不勾选时导出的仍是原来的 `app/ver/at/cfg/save` 结构。
- 把该 json 发给朋友，对方在主页或准备页点「导入存档」选择文件，即恢复为你的配置与进度（导入后自动刷新页面显示）。
- 想重新开始：主页「重置进度」或准备页「重置全部进度」即可清空后从头打（只清空**当前档案**的进度/配置两档，音量、震动、FPS、开镜方式、灵敏度、准星与键位等全局设置不受影响）。
- 全程本地 Blob / FileReader，零网络依赖；文件带 `app:'breach-door-cqb'` 标识与时间戳（导入时校验该标识，非本游戏存档一律拒绝）。

## 离线说明

- 四个页面均为自包含单文件：地图、AI、音效（WebAudio 合成）、存档（localStorage）全部本地实现。
- 界面图标使用本地 FontAwesome（`fontawesome-free-7.3.1-web/`，含 `css/all.min.css` 与 `webfonts/*.woff2`），四个页面通过相对路径 `<link>` 引入（`game/` 内页面为 `../fontawesome-free-.../css/all.min.css`），无需任何外部 CDN；请把整个 `fontawesome-free-7.3.1-web/` 文件夹与 `index.html`、`game/` 目录放在同一目录一起分发，断网本地即可正常显示图标。
- 界面不使用 emoji 字体，图标字体不随网络加载；任何环境均可本地显示。
- `tests/offline_test.js` 可随时复检零网络依赖（仅允许引入这一份本地 FontAwesome 样式表，已覆盖四个页面）。
- **无障碍**：四个页面都带 `<noscript>` 提示、开始/结算/暂停等覆盖层带 `role="dialog" aria-modal="true"`、
  击杀播报与提示条带 `role="status" aria-live="polite"`（读屏可听到战况），并尊重系统
  `prefers-reduced-motion`（关闭血条脉冲等动画；屏幕震动另有设置开关）。
- **色觉友好**：暂停菜单可勾选「色觉友好配色」，把阵营色从红/蓝换成**橙/青**（仅改视觉，不影响判定），
  偏好存 `breach_game_set.cbMode`；提示文字底色对比度已提到 WCAG AA。

```
    ├── street_stuck_probe.js  探针：长街卡死体检（接近/绕障/被围/整波/车缝/90s 随机走位）
    └── fog_probe.js           探针：像素级迷雾渐变检查
```

## 地图数据与预览的一致性

- 五张战役地图全部由 `game/breach.html` 内的 `buildMap*()` 构建器生成（房间 / 墙体 / 门 / 低掩体 / 装饰），
  出生点与巡逻点在 `MAP_RED` / `MAP_BLUES`，补给点在 `MAP_PICKUPS`；
- `index.html` 主页与 `game/hub.html` 的「地图预览」数据**不手写**：由 `node tests/preview_test.js --write`
  从上述构建器直接导出（写在两页的 `// <map-preview-data:auto>` 标记之间），
  `node tests/preview_test.js` 会校验预览与游戏几何是否仍然一致；
- 改地图的推荐流程：改构建器 → `node tests/map_probe.js <地图>` 核对可走性/出生点 → `node tests/maps_test.js`
  验证连通性 → `node tests/preview_test.js --write` 同步预览 → 跑完整测试集。
