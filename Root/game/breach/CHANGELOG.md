# 变更记录

本项目遵循语义化版本（`MAJOR.MINOR.PATCH`）。版本号回到 **3.x** 序列：v0.1.0 是首个公开版本，其后接 v3.4.0（逻辑修复）、v3.4.1（字体裁剪）、v3.5.0（移动端重写）与 v3.5.1（手机战斗横屏），代码注释中保留着 `v3.x` 的历史标记。

## [v3.5.1] — 2026-10-24 · 手机战斗画面锁定横屏

### 改动

- **战役 / 长街：手机竖屏不再进入战斗模拟**。检测到触屏设备且视口为竖屏时，盖一张「请横屏进入战场」提示并冻结主循环；旋转到横屏后自动继续，转回竖屏再次暂停。
- 提示页提供「尝试自动横屏」按钮：支持的浏览器（Android Chromium 等）会请求全屏并 `screen.orientation.lock('landscape')`；iOS / 不支持方向锁的浏览器会提示手动旋转，不阻断横屏后的正常游玩。
- 增加 `screen-orientation` / `x5-orientation` 元信息，方便部分国产浏览器进入横屏；桌面端与窄窗口键鼠路径不受影响。
- 竖屏遮挡层位于开始/暂停/结算/账户等所有覆盖层之上（z-index 100），不会出现“提示被结算页盖住”的空档。

## [v3.4.1] — 2026-10-24 · 字体裁剪 · 首屏图签修复

### 性能

- **FontAwesome 字体按实际用到的图标裁剪**：实心体 `fa-solid-900.woff2` 119 KB → **10.2 KB（8.8%）**、常规体 `fa-regular-400.woff2` 19.5 KB → **0.9 KB（4.7%）**。四页共用到 108 个图标（含 JS 里拼出来的奖杯/星形/药丸等），一个不落地进了子集；`brands` / `v4compatibility` 两份页面从不引用，浏览器按需才取，没动。CSS 的 `@font-face` 族名与字重不变，四页无需改动。
  本机实测（Pages + 本地证书代理）：裁前字体 1.9 s 才发起、2.7 s 才下完（119 KB）；裁后同样链路上 10 KB 量级，字体代价基本消失。重新裁剪：`npm i subset-font` 后 `node .uiwork/subset-fonts.js`；原始完整字体备份在 `归档/字体原始/`（不进仓库）。

### 修复

- **开始界面图签栏显示占位值**（`game/breach.html`）：图签刷新只在开局 / 暂停 / 结算 / 选图时触发，首屏一直显示静态的 `A / BR-CQB / 0:5`，于是 AI_README 里"看版次确认浏览器没在跑旧标签页"这条自查在首屏不成立。启动时补一次 `updateTitleBlocks()`。

## [v3.4.0] — 2026-10-21 · 逻辑修复版

按整份逻辑检查报告（6 高 / 12 中 / 19 低）逐条修复的一版，重点在"静默失效"和"会吃数据"的路径。

### 修复

- **击杀播报方向反了**（战役）：`killFeed` 用 `unshift` 写入（最新在前），HUD 却从数组尾部（最旧）往回数 —— 最旧一条一过期就整块不渲染，播报区长期空白，能显示时显示的也是最旧两条。改为从 `[0]` 起取最新 2 条。
- **屏幕震动污染确定性随机流**（战役）：`render()` 每帧消耗两次 `rng()`（`shake` 为 0 时也消耗），渲染帧数会改变命中/AI 的随机序列。震动改用 `Math.random()`。
- **跨局状态残留**（战役）：重开不复位 `lastBoardRank`（失败局结算页显示上一局榜名）与开镜状态 `mouse.ads` / `prevAds` / `camBeforeAds`（开镜中阵亡再开一局会一开局就是开镜态、首次关镜镜头跳一下）。`initGame` 一并复位。
- **世界准星坐标过期**（战役）：`mouseW` 只在 `mousemove` 时计算，中键平移/工具条缩放/窗口 resize/开镜插值改 `cam` 后都不重算 —— 屏幕准星不动但子弹飞向旧坐标。改为每帧按当前相机重算。
- **难度精度系数乘反**（战役）：`DIFF.acc` 被当成"误差倍率"用，导致困难难度敌人散布更大、简单难度更准，与字段语义相反；每日规则「精英敌人」的精度加成写进了局部副本、从未生效。改为误差 ÷ 精度，并让每日修正真正参与计算。
- **AI 换弹不扣备弹**（战役）：AI 直接 `mag = magSize`，绕过 `reserve`；玩家侧是 `min(need, reserve)`。改为同一口径。
- **个体清空全队记忆**（战役）：一台机器人到达目击点后 `myIntel.clear()` 把团队共享目标表整个清掉，另一台的追击/包抄/集火同时失效。改为只清本单位目标。
- **撤离失败后存活计数错乱**（长街）：撤离超时会紧接着再开一波（这是既有设计，保留），而 `startWave` 只把 `zombieAlive` 归零、不清残兵 —— 残兵被击杀扣的是新一波的配额，之后每波都提前判"肃清"、战斗中放行搭工事、战地急救失效。改为按真实存活数重算。
- **子弹打人会穿透**（长街）：打墙/打沙袋走位移线段扫掠，打人却只判本帧落点 —— 狙击枪一帧位移 43px 大于命中直径 28px，正面直射会被整帧跳过。改为线段-圆扫掠并取路径上最先命中的目标。
- **撕咬归一化取错对象**（长街）：`biteDmgScale` 读的是受害者（玩家/队友）的 `zAtkCd`（恒为 undefined），乘数恒 0.34 —— 尸王单口伤害偏高约 60%，丧尸类型在撕咬上没有差异。改为取攻击者的 `zAtkCd`。
- **工事寻路与碰撞不同口径**（长街）：寻路网格用不旋转的方块（`r + pad` 半边长）判堵，碰撞/子弹用可旋转 OBB，旋转 90° 后寻路仍绕一个不存在的大方块，工事封路判定也会误拒。改为网格里用 `circleOBB` 与碰撞共用同一变换。
- **开局横幅永远不可见**（长街）：`initGame` 把 `now` 归零却不重置 `bannerT`，"守住长街…"的年龄被算成 99 秒，透明度恒为 0。
- **工事同帧销毁漏处理**（长街）：`for...of` 里 `splice` 会跳过紧邻的第二座工事，改为倒序遍历。
- **账户读档回退不区分身份**（主页）：账户键为空时会回退读旧明文键 —— 游客模式玩过一局再登录账户会读到游客进度；`resetAll` 又只删密文键，重置后旧档"复活"。回退收窄为"本机还没有账户"时才允许。
- **用户名未转义**（主页 / 整备大厅）：账户名直接拼进 `innerHTML`（共 6 处），可注入脚本读取会话密钥。改为统一转义。
- **整备大厅会用旧快照覆盖存档**：存档只在启动读一次、每次写整份对象 —— 打完一局用浏览器「后退」回大厅再买升级，那一局收获被旧快照整个盖掉。新增 `pageshow` / `visibilitychange` 的按需重读（仅当磁盘内容与上次写入不一致时），并给升级/晋升的两档落盘加回滚。
- **升级半成功会白扣军功点**：`persistBoth` 用 `&&` 短路，一档成功一档失败时读回真实落盘内容，但 `save.points` 已经扣过。改为失败时两档都回滚到写之前。

### 平衡（沿用 v0.1.0 之后未发布的调整）

- **霰弹枪加强**（近战爆发名副其实）：弹匣 6 → **8**、备弹 40 → **56**、**8 颗弹丸 × 11 伤**（贴脸全中 88，一枪带走 60~76 血的守军；原来 6×9=54 连一具满血守军都打不死）、泵动射速 1.7 → **2.0 发/秒**、换弹 2.2 → **1.9s**、散布 0.075 → 0.065。0.1rad 固定扇面在远处自然散开（500px 处最多中 4 颗），所以它仍是"贴脸才强"的枪，而不是远近通吃的步枪。战役页、长街尸潮页、准备页数值三处同步。

### 排行榜

- **名次计算加难度系数**：榜单分 = 表现分 × 难度系数（简单 ×0.85 / 标准 ×1.0 / 困难 ×1.2），两张榜都改 —— 同表现下困难 > 标准 > 简单，高难度的高表现也能压过低难度的一档（例如困难 2 星 > 简单 3 星）。表现分把旧口径折成一个数、分项先后不变：战役 `星级×1000 + 击杀×10 + 用时奖励（600s 满分线，每快 1s 得 1 分）`，长街 `波数×1000 + 得分（每 10 分折 1 分，最多折 1000＝一波）`；榜单分相同才回落到旧分项逐项比。榜面板行尾直接显示「榜分」、难度标成 `困难 ×1.2`，名次为什么这么排一眼能算；系数集中在四个页面 `BOARD_DIFF_W` 一行，调平衡只改它。系数与榜分是**读榜时重算的派生值、不落盘**，所以老成绩不用迁移、改完系数立刻按新系数重排。
- 结算军功点口径、星级判定、榜单落盘上限（50 条/展示 10 名）与明文全机共用都不变。

### 修复（v0.1.0 之后、本版之前）

- **扳机延迟**：射速积分器由"只在按住时累积、松手冻结"改为"**待机回充、封顶 1 发**" —— 距上一发满 1/射速 秒后，按下左键**当帧出膛**。原来只有 `fireRate < 1.5` 的慢射速武器（狙击枪）享受"点击即射"，霰弹枪 1.7 发/秒要按住 **0.59s** 才响、快点一下完全没反应；现在霰弹枪 / 狙击枪 / 精确射手步枪全都没有扳机延迟，换弹完成与切枪也直接是"上膛待发"。掉帧大时间步下连射射速不变，连点也无法绕过射速上限（封顶 1 发）。

## [v0.1.0] — 2026-10-17 · 首个公开版本

首个 GitHub 公开发布。四个自包含单文件网页，零依赖、零联网、断网可玩。

### 玩法

- **红蓝对抗**：玩家 + 2 台友军机器人，肃清 4~6 台敌方机器人（按难度）。五张按真实空间逻辑建模的战役地图 —— 户型图（一梯两户板式住宅）、仓库（双深货架 + 3m 叉车巷道 + 装卸月台）、工厂（西进东出的工艺动线）、写字楼（中央走廊 + 独立单元）、地下车库（垂直式车位 + 单行车道 + 柱网），比例尺约 `1px ≈ 1cm`。
- **真实视线**：锥形视野 + 墙体/关门遮挡 + 战争迷雾 + 敌人脱离视野后的"最后目击"记忆标记（点划线圆 + 问号，不跟随实时坐标）。枪声暴露位置，敌人循声查探、破门突入。
- **战术 AI**：BFS 寻路（转角路点 + 轴分离滑墙穿门）、找掩体、侧翼包抄、反应延迟、低血撤退、掩护射击、倒地救援、听声查探。
- **战术工具**：破墙锤（砸开内隔墙生成新进攻路线，承重外墙不可破坏）、声源诱饵（调虎离山）、配电箱断电（全场变暗、双方视野同时收缩）、烟雾弹、炸药包（可炸毁家具，碰撞/视线/寻路自动重建）。
- **八种枪**：突击步枪 / 冲锋枪 / 霰弹枪 / 狙击枪 / 轻机枪 / 精确射手步枪 + 手枪副武器，各自独立弹匣与换弹进度；慢射速武器点击即射不蓄力。
- **战术指令**：`1`/`2`/`3` 选人，`X` 指令模式给队友下移动命令，`C`/`V`/`B` 跟随 / 固守 / 集火。
- **训练场**：`game/breach.html?range=1`，室内直线靶场，`1`~`6` 切枪，不判胜负、不计成就与战绩。
- **独立玩法《丧尸围城 · 长街尸潮》**：横向长街波次防守，无限波次、波后补给、每 3 波三选一强化（8 项）、每 5 波尸王、第 4 波自爆丧尸、第 7 波尖啸者；波间搭沙袋工事（可旋转 15°，按 OBB 参与碰撞/寻路/视线）、撤离窗口主动通关、有名字的队友永久阵亡与指挥点招募（B9 起无编制上限）。
- **成长**：军功点结算 → 18 项永久升级 → 军衔晋升（无等级上限）；15 项成就；7 条每日挑战；3 档档案；战役与长街各一张本地排行榜。
- **战后作业图**：整局走位画成工程图（红蓝轨迹、阵亡叉号、交火圈号、房间分区、比例尺、图签），一键导出 PNG。

### 系统

- **可选账户与本地加密存储**：页面内自实现 SHA-256 → 口令派生 → `SHA-256-CTR` 流加密 + `HMAC-SHA256` 截断 16 字节信封。没建账户时行为与旧版完全一致；游客模式每次重置；多账户（最多 8 个）；改口令用新口令重加密全部存档。
- **加密导出**：存档可选用口令加密导出（`sha256-ctr-hmac-v1`，`iter=40000` 写在文件头），错误口令 / 被篡改 / 非本游戏格式一律拒绝且不写入。
- **设置与改键**：音量、灵敏度、准星样式与大小、屏幕震动、FPS、命中提示、按住式开镜、色觉友好配色（橙/青）、自动开门，以及 22 项可改按键（冲突自动互换、可一键恢复默认），全部持久化。
- **无障碍**：`prefers-reduced-motion`、覆盖层 `role="dialog" aria-modal="true"`、战况 `aria-live`、WCAG AA 对比度、原生 input 保留键盘与读屏。

### 工程

- **25 个零依赖断言测试**（`npm test`）：把页面脚本送进 Node `vm` 沙箱，用假的 canvas / WebAudio / localStorage 跑真实逻辑，或直接读源码做结构断言；另有 4 个探针脚本（迷雾渐变指纹、地图可走性、地图转 PNG、长街卡死体检）。
- **`offline_test.js` 守离线**：任何 `http(s)://`、`@import`、`url(`、`fetch(`、`<script src=>`、外部字体与 emoji 依赖都会立刻失败。
- **地图预览数据由构建器导出**，主页与整备大厅的地图预览逐字节比对游戏内几何。
- **`doc_test.js` 守文档**（章节目录 vs 代码、README 声明的测试数量）、**`version_test.js` 守版本**（四页 `REV. 版次` / `VERSION.txt` / `package.json` / 本文件 / 打包脚本）。
- 发布层：GitHub Actions（测试 + Pages 部署）、MIT 许可证、第三方资源声明、`tools/serve.js` 零依赖本地服务器、Windows 安装器与打包脚本。

### 已知限制

- 没有触屏操作方案，只支持键鼠。
- 账户加密会挡住"随手翻看 / 随手改档"，但会话密钥存在 `sessionStorage` 里是明文的 —— 不是防有心人的密码学产品。
- 存档只在当前浏览器里，清站点数据即丢（请用导出存档留备份）。
- 安装包 `install.bat` 仅 Windows；网页形态跨平台。
